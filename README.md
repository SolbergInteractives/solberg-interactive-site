# Solberg Interactive

Landingssiden for Solberg Interactive. Ren HTML, CSS og litt JavaScript, ingen byggesteg.

```bash
python3 -m http.server 4321
```

- `index.html` – innholdet
- `styles.css` – stilen (kraftpapir, tekniske tegninger, «non-photo blue»)
- `main.js` – logo-animasjon, koordinater og scroll-avsløringer
- `assets/` – favicon, Betrayal-logo og The Balls-cover (hentet fra spill-repoene)
